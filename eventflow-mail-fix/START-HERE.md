# Что заменить

Архив содержит отдельные папки frontend и backend для двух ваших GitLab-репозиториев.
Скопируйте содержимое каждой в соответствующий репозиторий после сохранения своей работы.
Не удаляйте .git, .gitlab-ci.yml, policy.yml, существующий .env и data.sqlite3.
База и секреты в архив не включены.

В backend заменён server.py, обновлены README и .env.example, добавлены tests.
Во frontend добавлены config.js и api.js, обновлены страницы и скрипты, сохранён дизайн.
Перед первым запуском прочитайте backend/README.md и настройте Resend в локальном .env.
Ключи, базы и публикация автоматически не настраивались.
